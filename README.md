# 生肖年龄合盘（纯前端静态网页）

一个可直接部署到 GitHub Pages 的中文生肖 / 星座趣味合盘网页，无需任何后端服务，手机 / 电脑自适应，保留星空视觉主题。

## 功能

1. **生日速查（首屏入口）**：只输入一个公历生日（手机日期选择器 / 手动输入），分块展示输入的公历生日、生肖（含年份分界口径）、西方太阳星座（含日期区间）、农历生日（与生肖年分开表述）、传统性格 / 民俗参考、适合的恋爱对象星座速配参考、免责声明；未填时辰仍可查询，不宣称完整八字或星盘；结果区提供「用这个人继续做双人合盘」按钮。
2. **双人合盘（首屏入口，独立流程）**：双方各自输入公历出生年月日，分块展示生肖、分界规则、传统生肖关系（六合 / 三合 / 六冲 / 六害 / 相刑，同一组合多重关系显示「主要关系 + 兼有关系」）、星座参考卡（独立娱乐卡片）、实际年龄差（准确到年月日，说明谁年长、按当前日期算周岁，独立展示不参与评分）。
3. **民俗趣味参考值**：0-100 趣味分数命名为「民俗趣味参考值」（非恋爱成功率），标注为程序按固定规则生成的娱乐分值，展示构成（生肖关系基础分 + 纳音五行微调）；完全确定性（相同输入永远相同结果），交换双方顺序结果一致，无随机扰动；不使用「天作之合 / 灵魂伴侣」等确定性标签。
4. **生肖历法口径**：默认按春节（农历正月初一）分界，可切换为按立春（节气）分界；立春数据仅含日期不含交节时刻，不描述为精确排盘；立春当天出生时提示临界日并给出两种口径的生肖，不悄悄选定；程序默认按中国标准时间；农历转换、生肖年、干支纳音均使用同一权威数据（sxtwl 天文历生成并校验）。
5. **更多玩法（折叠区）**：每日运势（含时辰可选）、生辰测算（含时辰可选）、MBTI 性格搭配（独立于生肖合盘，不混成权威人格评分）。

## 运行与自测

- 直接双击 `index.html` 即可在浏览器打开（也可用 `npx serve` 等本地静态服务器）。
- 核心算法自测：`node temp/test_core.js`（星座 / 春节 / 立春边界、农历范围、生肖关系多重组合、契合度确定性与顺序无关、年龄差一天 / 一月 / 跨年 / 闰日边界、每日运势范围、文案红线）。
- 交互自测（模拟 DOM + alert）：`node temp/selftest.js`（速查单生日成功、临界日提示、未来 / 非法日期、继续合盘带入、合盘缺失提示、年龄差独立、分数命名与无扰动）。
- 浏览器实测：直接双击 `index.html` 打开（或 `npx serve` 本地静态服务器），人工检查：390px 视口无横向溢出、双入口首屏可见、速查 / 合盘全流程、交换顺序分数一致、立春口径切换、控制台 0 错误（temp 下暂未提供自动化浏览器脚本）。

## 部署到 GitHub Pages

1. 将本文件夹中的 `index.html`、`style.css`、`script.js` 上传到 GitHub 仓库根目录（可放在任意仓库或新建仓库）。
2. 仓库 → `Settings` → `Pages` → `Build and deployment` → `Source` 选择 `Deploy from a branch` → 选择分支 `main`（或 `master`）与根目录 `/` → `Save`。
3. 等待 1-2 分钟，访问 `https://<用户名>.github.io/<仓库名>/` 即可。

> 提示：若仓库名不是以 `.github.io` 结尾，也可把三个文件放进 `docs/` 目录并将 Pages 源目录设为 `/docs`。

## 规则限制与免责

- **纯前端、零收集**：所有计算均在浏览器本地完成，无后端、无账号系统；不收集、不上传、不写入 URL。
- **生肖历法**：默认按春节（农历正月初一）分界，可切换立春（节气）口径；立春数据仅含日期不含交节时刻，立春当天出生时如实提示临界日（按日期近似判断，非精确排盘）；程序默认按中国标准时间（CST）。
- **输入范围**：公历日期支持 1900-01-31 至 2100-12-31（农历数据自 1900-01-31 起）；未来日期、非法日期（月份 1-12、日按当月实际天数）一律弹窗提示且不计算结果。
- **不构成专业论断**：未提供出生时间 / 地点时不能宣称完成完整八字或星盘；生肖关系、星座速配、民俗趣味参考值均为文化娱乐参考，不宣称科学预测，不鼓励依据结果做重大现实决策。
